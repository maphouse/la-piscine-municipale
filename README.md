# la-piscine-municipale — FREE ADULT SWIM

A full-screen web map of **free adult-swim hours at Montreal's indoor municipal
pools**. Markers update live with the current Montreal time: their **size** shows
how much free adult-swim time is left today, their **colour** shows whether a pool
is open / opening later / done for the day, and their **opacity** shows how soon
the next free swim begins.

Live: https://maphouse.github.io/la-piscine-municipale/

## How it works

- **Frontend** — vanilla JS + [MapLibre GL JS](https://maplibre.org/) on a free
  CARTO Positron basemap (no API key). No build step.
  - `index.html`, `css/style.css`, `fonts/` (self-hosted [Libre Franklin](https://github.com/impallari/Libre-Franklin)).
  - `js/symbology.js` — colour / size / opacity from a pool's schedule + the
    current time (America/Toronto).
  - `js/ics.js` — generates a per-pool `.ics` of weekly-recurring free-swim events.
  - `js/i18n.js` — English/French legend strings.
  - `js/app.js` — map, markers, popups, legend, language toggle.
- **Data** — `data/pools.json`, generated by `scripts/scrape.mjs`.

### The data pipeline

`scripts/scrape.mjs` reads `scripts/candidates.txt` (a list of montreal.ca
`/lieux/<slug>` pages) and, for each page:

1. keeps it only if it describes an **indoor** pool (the page mentions a *piscine
   intérieure*);
2. reads the coordinates from the page's JSON-LD;
3. selects the schedule **period currently in effect** (pages list several periods
   — e.g. spring break vs. regular season — each tagged with a
   `<time datetime>` range);
4. extracts the **adult** (*Pour les adultes*) and **adult lane-swim** (*Nage en
   couloir*) sessions from that period's tables.

Pools that are closed / off-season (no current adult schedule) are omitted.

The City's open-data pool dataset is **not** used to classify pools: its 2023
snapshot miscategorises several real indoor pools. The pages' own wording is the
reliable signal.

## Updating the data

Schedules change only at seasonal shifts, so scraping runs rarely and on free
GitHub infrastructure:

- **`.github/workflows/update-data.yml`** — runs on the 1st & 15th of each month
  (and on demand via *Run workflow*), commits `data/pools.json` if it changed.
- **`.github/workflows/deploy.yml`** — deploys the static site to GitHub Pages on
  every push to `main`.

Run it locally (Node 18+, no dependencies):

```bash
node scripts/scrape.mjs        # rewrites data/pools.json
python3 -m http.server 8000    # then open http://localhost:8000
```

To add or remove a pool, edit `scripts/candidates.txt` and re-run the scraper.

## Caveats

The map shows the **main seasonal schedule** only. One-off closures and special
events are not tracked — use the **Visit pool page** link in each popup to confirm
before heading out.
